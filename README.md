# 🗂️ Экзаменационные Флеш-карточки (Exam Flashcards)

Небольшое локальное веб-приложение для самостоятельной подготовки к теоретическим экзаменам и зачетам по принципу карточек **Quizlet**. Приложение отображает интерактивную карточку с вопросом, которая плавно переворачивается по клику и показывает правильный ответ.

## 🚀 Основные возможности
* **Интерактивные карточки:** На лицевой стороне отображается вопрос, при клике по карточке (или нажатии `Пробел`) она переворачивается на 180° и показывает ответ.
* **Удобная навигация:** Переключение между вопросами кнопками «Назад» / «Вперёд» или стрелками на клавиатуре, с автоматическим возвратом карточки лицевой стороной вверх.
* **Режим тренировки:** Возможность перемешать колоду вопросов в случайном порядке и отслеживать прогресс изучения.
* **Локальный бэкенд на C++:** Легковесный и быстрый HTTP-сервер, отдающий вопросы из внешнего JSON-файла через REST API.
* **Горячее обновление базы:** Изменения в файле с вопросами применяются без перекомпиляции C++ сервера.
* **Современный фронтенд:** Быстрое SPA-приложение на **React + Vite**.

## 💻 Установка и запуск

### 1. Клонирование и подготовка базы вопросов

```bash
git clone https://github.com/Tsygankova-Maria/exam-flashcards.git
cd exam-flashcards
```

Убедитесь, что файл `backend/data.json` заполнен вашими вопросами и ответами в формате JSON-массива.

---

### 2. Сборка и запуск бэкенда (C++)
Откройте первый терминал и перейдите в папку бэкенда:
```bash
cd backend
```

Скомпилируйте проект с помощью Makefile:
```bash
make
```
*После успешной компиляции в папке появится исполняемый файл `server`.*

Запустите сервер:
```bash
./server
```
*По умолчанию бэкенд начнет слушать запросы на порту `8080` (`http://localhost:8080`). Не закрывайте этот терминал.*

---

### 3. Настройка и запуск фронтенда (React)
Откройте второй терминал и перейдите в папку фронтенда:
```bash
cd frontend
```

Установите все необходимые Node-зависимости:
```bash
npm install
```

Запустите локальный сервер разработки Vite:
```bash
npm run dev
```

В терминале отобразится локальная ссылка (обычно `http://localhost:5173`). Откройте её в любом браузере.

## ⚙️ Настройка своей базы вопросов

Приложение работает на основе файла `backend/data.json`, куда вынесены все карточки. Вы можете легко заменить демонстрационные вопросы своими билетами к экзамену.

### Формат файла (`backend/data.json`)
Файл представляет собой JSON-массив объектов. Каждая карточка **обязательно** должна иметь уникальный числовой идентификатор `id`, текст вопроса `question` и текст ответа `answer`.

**Пример заполнения:**
```json
[
  {
    "id": 1,
    "question": "Что такое инкапсуляция в ООП?",
    "answer": "Механизм объединения данных и методов, работающих с этими данными, в одном классе, а также сокрытие деталей реализации."
  },
  {
    "id": 2,
    "question": "Какова асимптотика бинарного поиска?",
    "answer": "O(log n) в среднем и худшем случаях при условии, что массив предварительно отсортирован."
  },
  {
    "id": 3,
    "question": "Чем стек (Stack) отличается от очереди (Queue)?",
    "answer": "Стек работает по принципу LIFO (последним пришёл — первым ушёл), а очередь — по принципу FIFO (первым пришёл — первым ушёл)."
  }
]
```

⚠️ **Важные правила при изменении файла:**
* **Синтаксис JSON:** Следите за тем, чтобы после последнего элемента в массиве или объекте **не стояла запятая**.
* **Кодировка:** Сохраняйте файл исключительно в кодировке **UTF-8**, чтобы кириллица в вопросах и ответах корректно отображалась в браузере.
* **Обновление данных:** Если сервер считывает `data.json` при каждом запросе, достаточно нажать кнопку обновления вопросов в интерфейсе (или обновить страницу в браузере). Если данные кэшируются при старте, перезапустите C++ сервер (`./server`) в терминале.

## 🎯 Использование приложения
1. Откройте приложение в браузере — на экране появится первая карточка с вопросом.
2. **Кликните по карточке** (или нажмите `Пробел`), чтобы перевернуть её и проверить свой ответ.
3. Используйте кнопки **«Назад»** и **«Вперёд»** (или стрелки `←` / `→` на клавиатуре) для перехода к следующему вопросу.
4. Нажмите **«Перемешать»**, чтобы изменить порядок карточек для более эффективного запоминания.
